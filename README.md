# DuckMath

The honest math of keeping backyard ducks: flock minimums and space, feed burn rate, realistic egg counts by breed, the daily water truth, and cost per dozen.

Static site. No build, no backend, no tracking. Open `index.html`.

- **Engine:** `engine.js` - pure functions, tested in Node.
- **App:** `app.html` - five cards (space, feed, eggs, water, cost) with flock presets.

Part of the App Factory: https://github.com/iLanis-agent/app-factory
